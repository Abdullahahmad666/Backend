# Blog Application — Backend

REST API for a blog application built with **Node.js, Express and MongoDB**.

> The source is currently stored as `server.zip`. Extract it to browse or run the code.

## Tech stack
Node.js · Express · MongoDB · Mongoose

## Run locally
```bash
git clone https://github.com/Abdullahahmad666/Backend.git
cd Backend && unzip server.zip && cd server
npm install
# create .env with MONGO_URI and PORT
npm start
```
